# 📁 ModuDrone-Labs Archive

This directory stores older CAD files, deprecated revisions, experimental parts, and
historical design snapshots from the ModuDrone project. Nothing in this folder is
considered current or production-ready — it exists so we can track the evolution of
the platform and reference past ideas without cluttering the main CAD workspace.

---

## 🗂️ What Goes Here

- **Old part revisions**  
  Components replaced by newer versions but still useful for measurements or reference.

- **Failed experiments**  
  Concepts that didn’t make it into the final design but may inspire future work.

- **Legacy assemblies**  
  Early prototypes, test rigs, and structural layouts showing how the drone evolved.

- **Temporary exports**  
  STEP, STL, or Parasolid files generated for slicing, simulation, or testing.

Code

---

## 📝 Usage Notes

- Files in this directory **should not be edited** unless adding metadata or documentation.
- If a file is revived or reused, move it back into the main CAD directory.
- When archiving a part, include a short note describing **why** it was archived.

Example:

AG-Motor-Mount-V2
Reason: Replaced by V3 due to insufficient wall thickness and clamp deformation.

---

## 🧠 Why We Keep an Archive

ModuDrone is a rapidly evolving platform. Keeping a structured archive helps:

- track design decisions  
- avoid repeating past mistakes  
- preserve useful geometry  
- document the engineering process  
- support future contributors  

This folder is the project’s memory — everything that got us to the current
design lives here.
